# Shared offline MSDF font

`game_ui`, `ui_gallery`, `ui_motion` and Shader Lab embed `ui.png` and `ui.json` at compile time.
They contain genuine multi-channel distances generated by **msdf-atlas-gen 1.4**.
There is no runtime font generator or system-font dependency for these samples.

Source: [NotoSansCJKsc-Regular.otf](https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf),
licensed under the included `OFL.txt`. Source SHA-256:
`2C76254F6FC379FDDFCE0A7E84FB5385BB135D3E399294F6EEB6680D0365B74B`.
Download this source to a local font source directory; verify the hash before reproducing.
The derived atlas is distributed under the same OFL license.

`charset.txt` contains ASCII, the sample Chinese UI vocabulary and Shader Lab's Chinese text, including the UI motion demo vocabulary.
From the sample repository root, generate with:

```sh
msdf-atlas-gen -font path/to/NotoSansCJKsc-Regular.otf -charset shared/msdf_font/charset.txt -type msdf -format png -size 48 -pxrange 8 -yorigin top -seed 0 -imageout shared/msdf_font/ui.png -json shared/msdf_font/ui.json
```

Expected: 512/512 glyphs, 1156×1156 atlas. Keep PNG and JSON together.
New characters require updating the charset, regenerating and rebuilding the sample.
Shader Lab labels (effect, Pass, Shader, folder and field labels in `src/shader_lab/shaders/*.oshader`) are collected
by `odin run tools/msdf_charset -collection:olib=../olib`, which appends missing codepoints to `charset.txt`
(it never removes any); add `-- -check` to only report them. Regenerate the atlas afterwards.
Shader Lab logs missing effect/Pass/Shader/folder/parameter-label glyphs after hot reload; it does not regenerate fonts.

`font <atlas-prefix>` in `game_ui` / `ui_gallery` loads `<atlas-prefix>.png` and
`<atlas-prefix>.json`. The loader checks `type=msdf`, `yOrigin=top` and matching image dimensions.
The default font remains embedded, so it works independently of the process working directory.

For visual checks, run `run.bat ui_gallery shot msdf`, add `scaled narrow` for 125% UI scale in a 760×760 output,
and run `run.bat shader_lab smoke` for native output, resize and hot-reloaded Chinese labels.
MSDF does not remove the need to inspect small text at its final pixel size.
